# MEDIA.txt -- where Hewlett-Packard's software and manuals are
#
# This repository does not carry them. It carries this list, which says
# what each file is, where it was downloaded from, and what it must hash
# to; tools/fetch-media.sh reads the list and fetches the files to the
# paths below.
#
#   tools/fetch-media.sh             the software the emulator boots (46 MB)
#   tools/fetch-media.sh --manuals   the manuals as well (230 MB), and
#                                    their text extractions in docs/notes
#   tools/fetch-media.sh --check     verify what is here, without network
#   tools/fetch-media.sh --list      this list, readably, with what is here
#
# WHOSE THEY ARE. Everything listed is Hewlett-Packard's: HP's software
# for the HP 9000 Series 500 (HP-UX also carries AT&T and University of
# California code), HP's manuals and internal specifications, and three
# issues of the Hewlett-Packard Journal. The copyright is theirs or their
# successors'. This project holds no licence for any of it, does not
# redistribute it, and states no terms for it: the files stay where their
# archives keep them, and fetching them is a download from those archives
# to your machine. The HP-UX 5.30 unit save is besides a real site's
# working system from 1991, with that site's accounts, home directories
# and mail as they were (software/README.md): run it, do not republish
# what is on it.
#
# WHERE THEY COME FROM. Two third-party archives, neither of them this
# project's, and a mirror of each:
#
#   bitsavers.org    the software (bits/HP/Crisis_Computer_Tapes) and the
#                    manuals (pdf/hp/9000_500, 9000_cio and disc).
#                    Mirror: bitsavers.trailing-edge.com.
#   hparchive.com    the three HP Journal issues. Mirror: the Internet
#                    Archive's Wayback Machine captures of the same URLs.
#
# Every URL below was downloaded once on 2026-10-03, primary and mirror
# alike, and its SHA-256 compared with the copy this project had been
# working from: all of them matched. A URL is listed only if it served
# those exact bytes. bitsavers.org refuses the default User-Agent of curl
# and wget (HTTP 403) and serves one that names its sender;
# tools/fetch-media.sh sends
# "hpfocus-fetch-media/<version> (+https://github.com/retrac0/hpfocus)".
#
# NOT LISTED HERE. The floppies in software/basic, software/demos and
# software/test and the tape software/97089C.hpi came from the HP Computer
# Museum (hpmuseum.net), whose downloads sit behind a CAPTCHA and cannot
# be fetched by a script; software/README.md has their provenance. The
# files that remain in docs/notes are this project's own OCR passes over
# the manuals and two page images, which no command reproduces byte for
# byte.
#
# FORMAT. Blank lines and lines starting with # are comments. Fields are
# separated by single spaces; no path or URL contains one.
#
#   file CLASS BYTES SHA256 PATH
#   <tab>url URL
#       A file to fetch to PATH (relative to the repository root). CLASS
#       is software (fetched by default) or manuals (--manuals). The url
#       lines that follow are tried in order: the first is the primary,
#       the rest are mirrors.
#
#   text MODE BYTES SHA256 PATH PDF
#       PATH is the text of PDF as pdftotext gives it: `pdftotext -layout
#       PDF PATH` for MODE layout, `pdftotext PDF PATH` for MODE plain.
#       tools/fetch-media.sh regenerates these once it has the manuals.
#       BYTES and SHA256 are what poppler 26.08.0 writes, which is what
#       the project's notes were made with; another poppler may differ in
#       whitespace, so a mismatch here is a warning, not an error.
