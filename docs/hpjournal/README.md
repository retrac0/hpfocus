# Hewlett-Packard Journal issues on the Series 500 — fetched, not carried

Three issues (August 1983, March 1984, May 1984) describe the Series 500's
processor, memory system and graphics. They are Hewlett-Packard's, and are
hosted by [hparchive.com](https://hparchive.com/).

    tools/fetch-media.sh --manuals

fetches them here with the other manuals; [MEDIA.txt](../../MEDIA.txt) has
their URLs and SHA-256s.
